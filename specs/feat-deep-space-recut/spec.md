# feat-deep-space-recut

## 背景与目标

将《深空》第一集从 22 个总长约 154 秒的独立分镜重剪为 15 个、总长 90–110 秒的连续微短剧分镜。目标是让相邻镜头能以动作、视线、光源或声音自然衔接，同时保留“系统载入失败、真有幽灵”的结尾悬念。

## 用户故事

- 作为创作者，我希望每个生成镜头都有明确的起始状态和结束状态，以便独立 T2V 成片剪接后仍具有连续动作与空间关系。
- 作为观众，我希望在约 100 秒内理解沈生苏醒、确认穿越、观察危机、听到传闻、遭遇幽灵并在系统失败中陷入绝境的因果链。

## 功能列表

### MVP（必须有）

- [ ] 将现有 22 镜头合并、重排为 15 镜头，单镜以 4–10 秒为主，总时长 90–110 秒。
- [ ] 将前半段压缩为连续的“受辱 → 苏醒 → 记忆确认 → 表面镇定”推进。
- [ ] 将中段组织为“人物观察 → 幽灵传闻/艾文神父信息 → 枪响 → 等待 → 攀爬与坠落”的递进危机。
- [ ] 将尾段组织为“幽灵建立 → 沈生反应 → 系统 99% 失败 → 黑色幽默绝境”的连续高潮。
- [ ] 每镜定义上一镜的连接锚点与本镜的落点；仅闪回、枪响和幽灵降临允许明确硬切。
- [ ] 更新英文 LTX 提示词，保留 4 句明确关键台词，并在群众声中保留幽灵蓝紫致死传闻和艾文神父/教堂信息。

### 后续迭代（可以有）

- [ ] 根据首个新镜头成片反馈迭代统一视觉锚点。
- [ ] 为剪辑软件输出转场和环境声轨提示。

## 技术方案概述

- 平台/运行环境：`data/gen.py`、`ltx-api` 的 22B dev standard 三阶段流程。
- 输入：静态英文分镜提示词表及每镜时长。
- 输出：逐镜 `preview.mp4`、`production.mp4`、`enhanced.mp4` 与可恢复 Stage 1 artifact。
- 关键约束：最终分辨率 1280×768；dev 快速档 12 steps、video CFG 2.5、audio CFG 7.0；保持逐镜输出，不自动拼接整集。

## 非功能需求

- 连贯性：默认通过同向视线、人物姿势、灯光方向、声音桥接完成转场；场景/时空变化才使用硬切。
- 提示词：每镜为英文单段提示，时长与内容密度匹配，描述镜头、动作、光线、环境声及必要的短台词。
- 可恢复性：更换提示词版本时使用新的输出根目录，避免和旧 22 镜状态文件混用。

## 已确认决策

- 目标长度：90–110 秒。
- 目标镜头数：15。
- 结尾：系统 99% 失败，沈生确认“真有幽灵”。
- 台词：保留水手羞辱、乔治幽灵传闻、迈克尔上楼、系统失败与沈生结尾；群众中保留蓝紫致死传闻和艾文神父/教堂信息。
- 推理档位：dev `fast`（12 steps、video CFG 2.5、audio CFG 7.0）。
