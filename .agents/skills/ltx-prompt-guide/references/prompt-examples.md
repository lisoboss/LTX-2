# LTX 2.3 提示词示例

## 例 1

外景：小镇街道——清晨——新闻直播。镜头切换到一位新闻记者，他站在一排被警戒线围住的汽车前，身后黄色的警戒线随风飘动。清晨的阳光温暖地洒在镜头上。空气中弥漫着人们低声交谈和远处钻井的声音。记者神情镇定，但显然很兴奋，他手持麦克风，直视着镜头。记者（直播）：“谢谢你，西尔维娅。是的——我从未想过会在电视直播中说出这样的话——但今天早上，就在佛蒙特州宁静的新城堡小镇……发现了黑金！”他微微指向身后的田野。记者（咧嘴一笑）：“如果我的摄影师把镜头摇过去，你们就会看到大家都在兴奋什么了。”镜头向右摇移，缓缓展现出一个建筑工地，工人们都戴着安全帽。一阵寂静——随后，一声巨响，一股石油从地底喷涌而出，猛烈地冲向空中。工人们欢呼雀跃，四处奔逃，黑色的油流在晨光中闪闪发光。镜头微微晃动，努力在混乱中保持对焦。记者（画外音，对着嘈杂声喊道）：“各位，这就是纽卡斯尔永生难忘的时刻！”镜头捕捉到阳光照射在油雾上的光芒，然后拉远，展现出整个场景——小镇的天际线在喷涌而出的石油映衬下显得格外醒目。

## 例 2

镜头切换到一间宁静祥和、阳光明媚的青蛙瑜伽教室。温暖的晨光洒在木地板上，香烟袅袅升起。资深青蛙教练盘腿坐在教室中央，双目紧闭，声音低沉而平静。“我们与池塘融为一体。”所有的青蛙都轻声回应：“嗡……”“我们与泥土融为一体。”“嗡……”他微微一笑。“我们与苍蝇融为一体。”停顿片刻。镜头转向一侧，一只青蛙突然抽搐了一下，眼睛四处乱瞟。突然，它的舌头猛地伸出，在半空中捕捉到一只苍蝇，然后把它拉进嘴里。教练缓缓吐出一口气，依然平静。“但是我们不能追苍蝇……”停顿。“上课的时候不能。”那只愧疚的青蛙低下头，双手合十，摆出冥想的姿势。其他青蛙继续吟唱：“嗡……”镜头在尴尬的青蛙身上停留了一会儿，它紧紧闭着眼睛，假装什么都没发生。
